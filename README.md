# 🦅 Vireon Digital — Futuristic Portfolio & Growth Engine

> **Growing Brands Through Social Media, Outsourced Sales & Autonomous AI Systems.**

A cutting-edge, high-performance web platform built for **Vireon Digital** featuring high-converting sales pipelines, digital marketing showreels, real-time ROI forecasting, and AI lead automation.

---

## ⚡ Core Features

- **Cyberpunk / Neo-Dark Glassmorphic UI**: Ultra-premium dark aesthetic with glowing cyan/teal neon accents (`#00F0FF`, `#00C49F`) and 60fps interactive particle constellation canvas.
- **Scalable SVG Branding**: Custom geometric falcon/swift emblem and stylized `VIRΞON DIGITAL` vector typography.
- **6 High-Impact Growth Pillars**:
  1. *Outsourced Sales Infrastructure* (Dedicated SDR pods & High-Ticket Closers)
  2. *Performance Digital Marketing* (Full-funnel Meta & Google Ads with 4.6x verified ROAS)
  3. *Viral Creator Growth & Video Mastery* (Hollywood-grade short-form editing for Reels, TikTok, Shorts)
  4. *Autonomous AI Growth Engines* (24/7 AI Voice Calling & WhatsApp/Instagram DM Bots)
  5. *SEO & AI Search Domination (GEO)* (Top Google rank & Generative Engine Optimization for ChatGPT)
  6. *Futuristic Web & High-Converting Funnel Architecture*
- **Interactive Video Showcase Theater**: Embedded showcase featuring video case studies with modal lightbox and category filtering.
- **Interactive ROI & Revenue Growth Calculator**: Real-time interactive sliders calculating monthly revenue lifts, closed deals, and 12-month ARR impact.
- **Interactive AI Growth Copilot**: Step-by-step diagnostic questionnaire providing instant custom growth blueprints.
- **Direct Concierge Channels**: WhatsApp one-click chat with pre-filled message, direct phone call button, and links to official [Instagram](https://www.instagram.com/digital.vireon) and [Facebook](https://www.facebook.com/people/Vireon-Digital/61592777193962/).
- **Cyber UI Audio Synthesizer**: Web Audio API-powered futuristic sound feedback with mute/unmute control.
- **Full SEO & Schema.org Markup**: Complete OpenGraph, Twitter Cards, and JSON-LD structured data.

## 🛠️ Project Structure

```
├── index.html              # Main semantic HTML5 application
├── config.js               # Centralized configuration (contact, socials, stats, services)
├── server.js               # Zero-dependency Node.js HTTP server with video streaming support
├── package.json            # Scripts & project metadata
├── css/
│   ├── main.css            # Core design system tokens, typography, grid, resets

│   ├── ai-copilot.js       # Interactive AI diagnostic questionnaire

    ├── logo/               # SVG vectors (vireon-logo.svg, vireon-icon.svg, favicon.svg)

```

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/sheraztariq033/viron-2.git
   cd viron-2
   ```

2. **Start the local server**:
   ```bash
   node server.js
   ```

3. **Open in browser**:
   Navigate to `http://localhost:3000`

---

## 🌐 Deploy to Vercel / Netlify

1. Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com).
2. It will deploy globally in under 15 seconds with zero build configuration needed.
